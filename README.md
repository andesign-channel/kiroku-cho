# きろく帳

配偶者からされたこと・言われたことを、日時つきで残すためのiPhone用Webアプリ。写真・スクショ・音声・PDFを添付でき、カレンダーと検索で振り返り、弁護士さんに渡すレポートを書き出せる。

- 記録は使う人のスマホの中だけに保存される。サーバーはなく、外部への通信もしない
- 同じURLを何人に配っても、記録は端末ごとに別々で、互いに見えない。配った側からも見えない

## 公開のしかた（GitHub Pages）

公開するのは**このフォルダの中身だけ**。専用の公開リポジトリの直下に置く。

1. GitHubで新しい公開リポジトリを作る（例: `kiroku-cho`）
2. このフォルダの中身をすべてそのリポジトリの直下に置いてプッシュする
3. リポジトリの Settings → Pages → 「Deploy from a branch」→ `main` / `(root)` を選んで保存
4. 数分後に `https://<GitHubのユーザー名>.github.io/kiroku-cho/` で開ける。これが配るリンクになる

URLにGitHubのユーザー名が入る。

## 使う人の導入手順（iPhone）

1. 配られたリンクを **Safari** で開く（LINEの中で開いた時は、右下のメニューから「Safariで開く」）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「きろく帳」から開く。以後は必ずここから開く

Safariのまま使った記録と、ホーム画面から開いた時の記録は別の場所に保存される。記録を始める前にホーム画面へ追加してもらう。

## 渡す前の実機チェック（iPhoneでしか確かめられない）

- [ ] ホーム画面に追加でき、アイコンから全画面で開く
- [ ] 機内モードにしても開ける
- [ ] 写真を添付できる／ボイスメモを「ファイルに保存」してから添付でき、詳細画面で再生できる
- [ ] 「すべてをバックアップする」→「保存する」→「ファイルに保存」でZIPが保存でき、そのZIPから復元できる
- [ ] レポートを保存して開き、共有の「プリント」からPDFにできる

## 更新する時

ファイルを1つでも変えたら、`sw.js` の `VERSION` を上げる（`v1` → `v2`）。上げないと、使っている人の端末には古い画面が残り続ける。ファイルを増やした時は `sw.js` の `FILES` にも足す。

更新しても、使っている人の記録は消えない。

## 動作の前提

- iOS 16.4 以降のSafari
- 暗証番号はのぞき見防止の簡易ロックで、記録の暗号化ではない

## 開発

```bash
npm test
```

判断を含む処理は `js/` 直下の純粋な関数に置き、`tests/` で検証している。手元で画面を見る時は `python3 -m http.server` などでこのフォルダを配信する（手元ではService Workerを登録しない。確認したい時はURLに `?sw=1` を付ける）。

アイコン（`icons/`）は図形だけの仮のもの。差し替える時は同じファイル名・同じサイズで置く。
